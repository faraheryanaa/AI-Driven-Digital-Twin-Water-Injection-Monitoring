# Water Injection Monitoring System

A machine learning-based water injection monitoring dashboard integrating anomaly detection and digital twin concepts to support operational monitoring and data-driven decision-making.

## Project Overview

This project focuses on developing a water injection monitoring system to identify unusual patterns in operational data and provide visual insights through an interactive dashboard.

By combining machine learning techniques with digital twin concepts, the system aims to support the monitoring and analysis of water injection operations.

## Project Objectives

- Explore and understand water injection operational data.
- Identify potential abnormal patterns using machine learning.
- Develop a monitoring dashboard to visualise operational information and anomaly detection results.
- Support better understanding of system behaviour through data-driven insights.

## Key Components

- **Data Understanding:** Explore and examine the available water injection dataset.
- **Data Processing:** Prepare and process operational data for analysis.
- **Machine Learning:** Apply anomaly detection techniques to identify unusual data patterns.
- **Dashboard:** Present monitoring results and visualisations through an interactive interface.
- **Digital Twin Concept:** Support the representation and monitoring of system behaviour using operational data.

## Installation and Setup

1. Clone this repository:

```bash
git clone https://github.com/faraheryanaa/water-injection-monitoring.git
```

2. Navigate to the project directory:

```bash
cd water-injection-monitoring
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

4. Open the `FYP Code` directory and follow the application setup instructions.
